ℹ️ About MediVerify AI Project

Medicine Authenticity Verification Using Machine Learning: Project Architecture, Technologies, and Regulatory Scope.

💡 Executive Summary & Problem Statement

The World Health Organization (WHO) estimates that up to 10% to 15% of medical products circulating in low- and middle-income nations are either substandard or falsified. Counterfeit medicines lead to therapeutic failures, antimicrobial resistance, organ toxicity, and severe economic harm.

MediVerify AI is designed as a rapid, accessible first-line screening interface. It allows healthcare workers, pharmacists, and consumers to inspect packaging metadata against verified pharmaceutical registries and apply machine learning classification models to detect subtle anomalies (e.g., manufacturer mismatches, corrupted batch syntax, chronologically invalid dates, and irregular stability durations).

🏗 Two-Tier Analytical Verification Architecture
Tier 1: Reference Registry Deterministic Verification

The system queries a curated reference dataset of authorized medicines (currently containing {{ registered_count }} registered formulations including Cipla, GlaxoSmithKline, Sun Pharma, Abbott, Dr. Reddy's Laboratories, and Alembic). It validates whether the drug name exists and whether the manufacturer holds the authorized license.

Tier 2: Scikit-Learn Anomaly Classifier

Extracts 9 numerical features (name similarity, manufacturer match, batch prefix, regex formatting, date sequence, shelf-life deviation, and batch Shannon entropy) and evaluates them using a trained Random Forest / Decision Tree Classifier to identify counterfeit anomalies.

🧪 Machine Learning Methodology & Features

The model is trained on calibrated pharmaceutical surveillance records with real-world anomaly patterns. The engineered feature set includes:

  • Name Match Score (Float 0.0 - 1.0): Degree of similarity between entered drug name and registered formulations.
  • Manufacturer Authorization (Float 0.0 - 1.0): Verifies if the entered producer matches the approved license holder.
  • Batch Prefix Validation (Binary 0 / 1): Confirms whether the leading characters correspond to the manufacturer's syntax code (e.g., CIP for Cipla, GSK for GlaxoSmithKline).
  • Batch Syntax Structure (Binary 0 / 1): Checks standard alphanumeric formatting (length 5-12, no illegal punctuation or emojis).
  • Date Chronology Sequence (Binary 0 / 1): Detects glaring packaging errors where Expiry Date precedes Manufacturing Date.
  • Shelf-Life Stability Duration (Months): Calculated months between manufacturing and expiration.
  • Regulatory Shelf-Life Deviation (Months): Measures absolute difference against approved stability limits (typically 24 to 36 months).
  • Batch Shannon Entropy (Float): Measures character randomness to flag repetitive dummy strings (e.g., AAAA0000).
⚠️ Critical Regulatory Disclaimer & Limitations

Crucial Safety Principle: Successful verification on MediVerify AI confirms that the entered packaging data, manufacturer name, batch prefix, and shelf-life parameters match official reference specifications.

Database matching does NOT prove that a physical medicine is genuine. Counterfeiters occasionally copy legitimate batch numbers and genuine packaging from authentic products. Genuine chemical verification requires physical laboratory testing, such as High-Performance Liquid Chromatography (HPLC), Mass Spectrometry, or Near-Infrared (NIR) spectroscopy to confirm Active Pharmaceutical Ingredient (API) purity and dissolution profiles.
